# Linux-Apps

Small Linux applications I build and actually use.

| App | What it is |
|---|---|
| [**BetterBanana**](BetterBanana/) | A virtual audio mixer for PipeWire, modelled on Voicemeeter Banana. Routing matrix, virtual cables, sidechain ducking, per-application routing, VBAN and a recorder. |

## Install BetterBanana

    curl -fsSL https://raw.githubusercontent.com/Zykoraa/Linux-Apps/main/BetterBanana/install.sh | bash

Handles dependencies, build, install and the background service on Arch,
Debian/Ubuntu, Fedora and openSUSE.

Each app builds independently — see its own README. Everything here is MIT
